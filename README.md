# EPD Tool VI

Trang web điều khiển EPD CC2640R2 / SSD1619 BWR.

## Cách dùng

Mở bằng GitHub Pages hoặc một web server HTTPS. Web Bluetooth thường không hoạt động nếu mở trực tiếp bằng `file://`.

## GitHub Pages

Sau khi upload thư mục này lên GitHub:

1. Vào repository trên GitHub.
2. Chọn **Settings**.
3. Chọn **Pages**.
4. Ở **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/root**
5. Bấm **Save**.

Sau vài phút GitHub sẽ tạo link dạng:

`https://ten-user.github.io/ten-repo/`
